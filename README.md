
# Unicrib 🏠

A student accommodation web application that connects university students with landlords around Harare, providing a scam-free alternative to traditional accommodation agents.

🌐 **Live Demo:** [unicrib11.netlify.app](https://unicrib11.netlify.app)

---

## 📌 About The Project

Finding student accommodation in Harare can be stressful and risky due to untrustworthy agents. Unicrib solves this by connecting students directly with verified landlords, making the process safer, faster, and more transparent.

---

## ✨ Features

- Browse available student accommodation around Harare
- Direct connection between students and landlords
- No middlemen or agents
- Simple and easy to use interface

---

## 🛠️ Built With

- React
- JavaScript
- CSS
- Deployed with Netlify

---

## 🚀 Getting Started

To run this project locally:

```bash
git clone https://github.com/kings-09/unicrib.git
cd unicrib
npm install
npm start
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
